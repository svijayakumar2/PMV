# Legacy Artifacts

This directory stores historical notes and experiment artifacts that are not part of the active runtime package.

## Contents

- `docs/`
  - archived design notes and one-off system writeups
- `results/`
  - archived log-analysis outputs and historical meeting-pack material

## Intent

- keep the top-level `pmv/` package focused on runnable code, configs, and scripts
- avoid deleting prior work while keeping active paths cleaner
